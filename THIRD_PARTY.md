# Third-party sources

- **Mathlib** ([leanprover-community/mathlib4](https://github.com/leanprover-community/mathlib4)), Apache-2.0. Pinned to `d13f23b723b8a846827a245b89c10fc7d3f11612` in `lake-manifest.json`; used for complex analysis, topology, compactness, real analysis and tactics. Mathlib source is a Lake dependency and is not copied into this tree.
- **OpenAI's mathematics library** ([openai/math](https://github.com/openai/math), `lean/`), Apache-2.0 ([OAI/LICENSE](OAI/LICENSE)), copied from commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`. Direct imports include `OAI.Analysis.SymmetricDomains.MontelExpandingDomains`, `OAI.Analysis.Crouzeix.Montel`, `OAI.Analysis.Crouzeix.Hurwitz` and `OAI.Probability.SLE.AngularLaws`.
- **TauCeti** ([TauCetiProject/TauCeti](https://github.com/TauCetiProject/TauCeti)), Apache-2.0 ([TauCeti/LICENSE](TauCeti/LICENSE)), copied from commit `3bed7e37f3c504a99e8c07e9f309540812a7aa90`. Direct imports include `TauCeti.Analysis.Complex.Conformal.RiemannMapping.Normalization`, `TauCeti.Analysis.Complex.Conformal.RiemannMapping.Equivalence` and `TauCeti.Analysis.Complex.Conformal.SchwarzPick.Basic`, providing normalized Riemann maps and Schwarz–Pick estimates.
- **FixedPointTheorems** ([harfe/fixed-point-theorems-lean4](https://github.com/harfe/fixed-point-theorems-lean4)), MIT ([FixedPointTheorems/LICENSE](FixedPointTheorems/LICENSE)), copied from commit `770940ddf9878cf61952ed53d910b92bca841838`. `FixedPointTheorems.brouwer` supplies the finite-dimensional Brouwer fixed-point result used for the product-of-intervals shooting argument.

Only the source modules in the Lean import closure are included for the three vendored libraries; their source files are unchanged. Each library's license is retained beside its modules.
