# Third-party sources

- **Mathlib** ([leanprover-community/mathlib4](https://github.com/leanprover-community/mathlib4)), Apache-2.0. Pinned to `56a005855ea17e0b0958f73ec801ae140b0a1679` (the `v4.35.0` tag) in `lake-manifest.json`; used for complex analysis, topology, compactness, real analysis and tactics. Mathlib source is a Lake dependency and is not copied into this tree. The project toolchain is Lean `v4.35.0`, the same as Mathlib's toolchain at that revision.
- **OpenAI's mathematics library** ([openai/math](https://github.com/openai/math), `lean/`), Apache-2.0 ([OAI/LICENSE](OAI/LICENSE)), copied from commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`. Direct imports include `OAI.Analysis.SymmetricDomains.MontelExpandingDomains`, `OAI.Analysis.Crouzeix.Montel`, `OAI.Analysis.Crouzeix.Hurwitz` and `OAI.Probability.SLE.AngularLaws`.
- **TauCeti** ([TauCetiProject/TauCeti](https://github.com/TauCetiProject/TauCeti)), Apache-2.0 ([TauCeti/LICENSE](TauCeti/LICENSE)), copied from commit `3bed7e37f3c504a99e8c07e9f309540812a7aa90`. Direct imports include `TauCeti.Analysis.Complex.Conformal.RiemannMapping.Normalization`, `TauCeti.Analysis.Complex.Conformal.RiemannMapping.Equivalence` and `TauCeti.Analysis.Complex.Conformal.SchwarzPick.Basic`, providing normalized Riemann maps and Schwarz–Pick estimates.
- **FixedPointTheorems** ([harfe/fixed-point-theorems-lean4](https://github.com/harfe/fixed-point-theorems-lean4)), MIT ([FixedPointTheorems/LICENSE](FixedPointTheorems/LICENSE)), copied from commit `770940ddf9878cf61952ed53d910b92bca841838`. `FixedPointTheorems.brouwer` supplies the finite-dimensional Brouwer fixed-point result used for the product-of-intervals shooting argument.

Only the source modules in the Lean import closure are included for the three vendored libraries. Each library's license is retained beside its modules. Release `v1.0.0` copied these files unchanged. This branch modifies them for Lean `v4.35.0` and the module system.

## Modifications

`scripts/check_vendor.py` rebuilds every vendored Lean file and license from commit `b69b82f04a5c17b46532cfb15e4e48005a28bf11` plus `scripts/vendor.patch.gz`. A change that is not in that patch fails the check and names the file.

- **OAI** (Apache-2.0), from `adc7f1241b42e322a6451854ab7e4b4c146bf78a`. Every file carries a notice before `module`. The change is a module header: `module`, public imports, and `@[expose] public section`. `OAI/Probability/SLE/RadiusClocks.lean` also inserts `NNReal.coe_min` so a minimum of extended nonnegative reals matches after coercion to `ℝ`.
- **TauCeti** (Apache-2.0), snapshot `3bed7e37f3c504a99e8c07e9f309540812a7aa90`. Twenty-three modules are replaced by the same paths at upstream `0535b3bf5a083a09c92f18f3f8aa2017f32a803c`, which adapts them to a later Mathlib revision on Lean `v4.35.0-rc3`. `TauCeti/Topology/ContinuousMap/Ascoli.lean` is added from that commit because `TauCeti.Analysis.Complex.Conformal.Montel.Precompact` imports it. The other TauCeti files are unchanged from the snapshot. Each changed file names both commits before `module`.
- **FixedPointTheorems** (MIT), snapshot `770940ddf9878cf61952ed53d910b92bca841838`. The five modules are the upstream port at `93a3eed3364281a9dbf9652bb52356a8db65057c` (Lean `v4.35.0` and the module system), with module documentation added. The MIT license file is unchanged.
